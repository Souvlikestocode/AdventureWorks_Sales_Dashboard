# AdventureWorks Bikes Sales — Power BI Dashboard

A Power BI dashboard exploring sales and returns across regions, products, and customer demographics for the AdventureWorks Bikes dataset. The dashboard features a left-hand toolbar for seamless navigation to the report pages


## Objectives

- Turn raw sales/returns data into actionable insights for the Sales and Marketing team

- Provide role-specific views for technical and non-technical stakeholders based on the depth they information they are looking for 

- Keep the experience dynamic & user-friendly with custom navigation.


## Report Pages

Executive Overview — High-level KPIs and trends for leadership teams

Geographical Insights — Map-led view of top regions by orders, sales, and returns.

Product Insights — Category- and SKU-level performance, including return rates.

Customer Insights — Behaviour, loyalty, and demographics for better targeting.


## Key Insights (from this build)

Top Region: United States of America — 8,700 orders, 2.12% return rate.

Product Highlights: Accessories lead with 16,983 orders; Bikes show the highest return rate (3.08%).

Customer Trends: Professionals + Skilled Manual ≈ 55% of orders.

Trends: 2021 orders +10% vs 2020; overall return rate steady at ~2.2% (Bikes higher at 3.08%).
